# UrduKitab AI

## Project Overview
An end-to-end Urdu OCR and Citation-Aware RAG system.

## Project Objectives
- Extract Urdu text from scanned PDF books.
- Preserve original book names and page numbers.
- Store document embeddings in Qdrant.
- Answer questions using Retrieval-Augmented Generation.
- Provide verified citations with every answer.
- Integrate the backend with a Flutter application.

## Technology Stack
- Python
- Tesseract OCR
- FastAPI
- PostgreSQL
- Qdrant
- Docker
- Git and GitHub
- Flutter
